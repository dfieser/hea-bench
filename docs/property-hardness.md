# Model card: hardness (tier B)

Generated by `tools/property_cards.py` with hea-bench 2.8.0 on 2026-10-08.

## Data

Source: Borg et al. 2020 (Sci. Data 7, 430; CC-BY-4.0 figshare deposit mirrored in `data/raw/borg2020/`). 417 unique (formula, processing) alloys carry a near-room-temperature Vickers hardness after the loader rules (median over repeat measurements, test temperature at most 35 C). 384 of them are fully descriptor-scorable and form the training population: 347 distinct compositions in 117 alloy systems, HV 109 to 1183. A composition measured after two processing routes is two rows, and the model pools them, so processing is part of the scatter the interval absorbs. Both rows always share a cross-validation fold, because folds hold whole systems.

## Model and held-out error

Random forest (300 trees, seed 0) on the package's 14 matrix descriptors. The released model trains on every alloy, and its 90 percent interval is the prediction plus or minus 207 HV, the conformal threshold of its own five-fold cross-validation errors over whole alloy systems. The table tests that procedure by nested cross-validation. Each of five outer folds holds out whole systems, and the interval is set inside the remaining four exactly as the released model sets it on all data.

| quantity | value |
|---|---:|
| held-out mean absolute error | 97 HV (fold-to-fold standard error 10) |
| held-out median absolute error | 71 HV |
| interval coverage, every alloy (nominal 90%) | 0.956 (fold-to-fold standard error 0.013) |
| interval coverage, alloys of 750 HV or harder | 0.932 (55 of 59) |
| mean interval width in the nested study | 489 HV |
| released interval width | 414 HV |

## What this error does and does not support

The interval is a screening tool. Two alloys whose predictions differ by more than the released width, 414 HV, have intervals that do not overlap, which is enough to triage a palette before synthesis. Candidates closer than that are not ranked by this model, and the API's intervals overlap visibly for such pairs. Conditioning on one processing route is available and shrinks the population (the floor refuses below 50 alloys).

## Deliberately not shipped

Yield strength: the same deposit carries 1,067 strength rows, but they span test temperatures from ambient to 1000 C with uneven strain conditions; a pooled fit would predict an ill-defined quantity, and the near-room-temperature subset thins per system to where family-grouped validation is not meaningful. Elastic moduli and experimental ductility: too few rows after the same filters. Corrosion and oxidation measures: no adequately licensed public dataset at screening scale. These return as tier B properties if and when a licensed dataset supports a defensible held-out error; the omission is the honest outcome, not a roadmap gap.
